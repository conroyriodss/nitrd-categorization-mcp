# Project documentation

This directory holds this entry's own project documentation: plans, runbooks,
decision records, testing limitations and analysis notes, written for the NIH
NITRD Categorization MCP Suite. It contains no vendor-contributed material.

The GSA template uses `docs/` for partner reference materials contributed by
IBM and Databricks, with a GSA non-endorsement notice. This entry repurposed the
directory; see [CONFORMANCE.md](../CONFORMANCE.md), difference 5. Mentions of
Databricks products here describe where the prototype runs; they are not
endorsements by NIH, GSA or the United States Government.
